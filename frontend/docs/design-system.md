## 2. Typography

- Geist Variable: English and French.
- Noto Sans Arabic Variable: Arabic fallback.
- Headings: Bold.
- Section titles: Semibold.
- Body: Regular.
- Secondary text: Smaller size and muted color.

## 3. Icons

- Library: lucide-react.
- Small icons: 16px.
- Default icons: 20px.
- Sidebar icons: 22px.
- Large icons: 24px.

## 4. Reusable Components

1. Button
2. Card

4. Label
5. Select

7. Avatar

11. Dialog

## 5. Development Rules

- Reuse existing UI components.
- Do not create duplicate buttons or inputs.
- Use shared color tokens.
- Keep spacing and typography consistent.
- Support RTL and LTR.
